# Support

hasr is free and open source, maintained by one person in their own time.

## Where to ask

- **A bug in hasr**: [open an issue](https://github.com/mohammedsafaaxp/Hasr/issues/new/choose) with your ERPNext and
  Frappe versions, what you did, what you expected and what happened. A screenshot helps.
- **An idea or a missing feature**: open a feature request with the same link.
- **A question about ERPNext itself**, not hasr: the [Frappe forum](https://discuss.frappe.io) is the best place.

## What to expect

- Issues are read every week. A fix for a bug that stops receiving or counting comes first.
- Supported versions: ERPNext v15 and v16, on the releases tested in CI (see `.github/workflows/ci.yml`).
- Older ERPNext versions and changes made to ERPNext's own code are not supported.

## Security

Please do not report a security problem in a public issue. Use GitHub's
[private vulnerability report](https://github.com/mohammedsafaaxp/Hasr/security/advisories/new) instead.
